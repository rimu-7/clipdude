## What's new

- **One click to open** — click the menu bar / tray icon and ClipDude appears. Right-click for the menu.
- **Automatic updates** — ClipDude now tells you when a new version is out and installs it in one click, with live download progress.
- **Faster, lighter, and more reliable** — clipboard history is now handled natively, with no more choosing a database file on every launch.
- **Smarter cleanup** — choose how long to keep clips and how many; ClipDude shows how many will be removed before deleting anything.
- **Privacy** — copies that password managers mark as private are never saved, and you can choose to skip anything that looks like a card number or API key.
- **Custom shortcut** — pick your own global shortcut in Settings.

## Fixes

- Fixed "database disk image is malformed" errors caused by an old search index. Your database also shrinks considerably.
- Fixed the window needing two clicks to appear.
- Fixed auto-delete settings that removed clips while dragging the slider.
